## Run locally
1. Download or clone this repository.
2. Open `index.html` in a modern browser.

No build tools or package installation are required.

## Publish with GitHub Pages
1. Open the repository on GitHub.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Select branch `main` and folder `/ (root)`.
5. Click **Save** and wait for GitHub Pages to publish the site.

## Before using this portfolio for applications
- Verify all dates, degree status, GPA, training titles, and contact details.
- Add public project screenshots or a demo link only when they are ready.
- Do not publish customer records, internal dashboards, confidential company documents, or personal data belonging to others.
- Keep the descriptions factual. Do not claim warehouse, inventory, ERP, or distribution experience unless you have actually gained it.
